# Issue tracker: GitHub

Les issues et PRD de ce dépôt vivent dans GitHub Issues. Utiliser le CLI `gh` pour les opérations.

Dépôt : `foucault-watt/centraliz`

## Conventions

- Créer, lire, commenter, labelliser et fermer les tickets avec `gh issue`.
- Les PR externes ne sont pas une surface de triage.
- Lorsqu’un skill demande de publier un ticket, créer une GitHub Issue.
- Lorsqu’un skill demande le ticket pertinent, lire son corps, ses commentaires et ses labels.
- Représenter les dépendances avec les dépendances natives GitHub.
- Si cette fonctionnalité GitHub n’est pas disponible, ajouter `Blocked by: #...` dans le corps.
- Appliquer `ready-for-agent` aux tickets suffisamment spécifiés pour être implémentés.
