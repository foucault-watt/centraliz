# Domain docs

Le dépôt utilise une documentation single-context.

Avant d’explorer le projet :

- lire `CONTEXT.md` lorsqu’il existe ;
- lire les ADR pertinents sous `docs/adr/` ;
- employer dans les tickets et tests le vocabulaire défini dans `CONTEXT.md` ;
- signaler explicitement toute proposition contredisant un ADR existant.

Ces documents sont créés progressivement lorsque des décisions de domaine sont réellement établies. Leur absence ne doit pas bloquer le travail.
