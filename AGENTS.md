## Agent skills

### Issue tracker

Les tickets sont suivis dans GitHub Issues. Voir `docs/agents/issue-tracker.md`.

### Triage labels

Les cinq labels canoniques de triage sont utilisés sans renommage. Voir `docs/agents/triage-labels.md`.

### Serveur de jeu Pokémon

Les tests, captures et diagnostics du serveur de jeu se font à distance avec `npm run pokemon:remote`. Il n'y a pas besoin de demander à l'utilisateur d'envoyer des captures. Voir `docs/agents/pokemon-server.md`.

### Domain docs

Le dépôt utilise une documentation de domaine single-context. Voir `docs/agents/domain.md`.
